# ContentFlow 系统能力概览

ContentFlow 面向需要持续生产、审核和分发多平台内容的运营团队，将分散的模型调用、知识检索、素材任务与平台接口组织为一条可追踪的业务流程。

## 业务闭环

1. 运营人员维护结构化营销 Brief，并导入经过确认的品牌与产品知识。
2. 系统检索相关知识块，由有界内容 Agent 比较选题、建立证据账本、生成平台化内容并执行编辑评审与最多一次定向修订。
3. 规则校验和模型校验先处理格式、禁用表达与事实风险，人工审核作为发布前门禁。
4. 审核通过后，人工上传、AI 生成、开放授权搜索或混合图片候选进入持久化队列；选择、许可来源、重试和产物均可追踪。
5. 连接器根据平台开放能力执行发布或导出，并回收或录入指标用于复盘。

## 核心工程能力

- FastAPI、SQLAlchemy、Alembic 与 PostgreSQL/SQLite 双模式数据层
- pgvector/HNSW 向量检索与离线 Hash Embedding
- OpenAI-compatible 文本/Embedding、中立 HTTP 媒体契约及本地 Mock Provider 适配
- 有界内容工作室 Agent、九维质量评审与修订回归保护
- 声明式、版本化、哈希校验的工作区风格 Skill；不加载用户代码
- 受限 Openverse/Wikimedia 开放授权图片搜索、人工许可确认和混合候选选择
- 数据库任务队列、租约、幂等键、指数退避与失败记录
- MinIO/S3 兼容对象存储和受控文件下载
- 多工作区隔离、RBAC、凭据加密和审计日志
- 抖音、微信公众号和小红书导出连接器
- 响应式运营工作台与 Docker Compose 部署

## 可靠性边界

- Mock Provider 只用于本地开发和流程验收，不会标记为真实外部发布。
- 真实平台能力取决于账号权限、应用 scope 和平台审核状态。
- 内容编辑后旧素材自动失效，发布 Worker 会再次校验审核状态、内容版本和素材状态。
- 外部凭据仅加密存储，API 响应和日志不会返回原始密钥。
