## A01/A02 本轮设计要点

- 所有用户发起的素材重试、来源切换、候选下载、已有素材替换、内容重新审批和通用 Job 重试复用检查。未解决人工核对、活动任务、未核对的生成/轮询账本分别处理。
- 风险记录跟随同一内容的素材历史，正文改版不能把旧 unknown 藏起来；活动任务只约束当前素材，正常混合候选可并行。
- API 统一先锁 ContentItem，再锁 Asset，随后锁 Job；等待后重新读取，防止旧状态通过。新增真实 PostgreSQL 的重试/切来源竞争测试。
- `request-manual-review` 仅审核者可用，只把已终止素材生成/轮询失败转入核对，不声称已核实，也不调用供应商；核对后复用原 Job 重试，不另开双份任务。历史 attempt 原样保留。
- 下载/搜索是只读操作，不将其失败误当作新的生成费用；保留媒体契约的同键自动恢复，人工重新操作仍受门禁保护。
- 修正复审的幂等证据表述：本地账本键与实际媒体生成幂等键不同，新 Job 并不必然导致重复扣费；供应商履约仍需外部验证。
- 来源测试覆盖 12 种 manual/generate/search/hybrid × manual/http/mock，以及人工上传后编辑、人工视频来源和 AI 配置缺失；无真实媒体调用。
- 原有完整流程测试依赖“默认 manual 却自动生成”的旧缺陷，现明确声明 `image_source=generate`，保留实际生成/导出断言，不删断言来制造通过。
