# ContentFlow 系统使用手册

本文面向内容运营、审核人员和工作区管理员，说明如何完成一次从知识入库到发布复盘的内容任务。部署、备份和故障处理见[生产部署与运维](operations.md)。

## 1. 登录与工作区

首次使用时，在登录页切换到“注册”，填写姓名、邮箱、密码和工作区名称。注册者自动成为该工作区管理员。

登录后，页面顶部会显示当前工作区。一个账户可以加入多个工作区，使用顶部下拉框切换。活动、知识、内容、素材、平台连接和审计记录都按工作区隔离。

浏览器会话会在后台安全续期，访问令牌不会保存到页面脚本可读的存储中。点击左下角退出会立即撤销当前会话；如怀疑账号泄漏，应由管理员要求用户退出全部会话并重新登录。

角色与权限：

| 角色 | 可执行操作 |
|---|---|
| 只读成员 `viewer` | 查看活动、内容、素材、发布、指标和任务状态，下载已就绪素材或投放包 |
| 内容编辑 `editor` | 包含只读权限；维护活动、上传知识与素材、启动生成、编辑内容、重试任务 |
| 审核人员 `reviewer` | 包含编辑权限；通过或驳回内容、安排发布、回收平台指标 |
| 管理员 `admin` | 包含审核权限；管理平台凭据、成员、工作区和审计记录 |

## 2. 准备知识库

进入“知识库”，上传经过确认的品牌规范、产品事实、服务范围或历史优质内容。支持 Markdown、TXT、CSV 和 JSON，单文件最大 20MB。

上传后状态会依次变为“等待中”“索引中”“已索引”。只有已索引资料会参与检索。若状态失败，到“任务队列”查看错误，修复文件后重新上传，或由编辑人员重试任务。

建议：

- 把可核实的产品事实写成短句，避免把推测或宣传口号当作事实。
- 品牌语气、禁用词和合规要求可以单独建文档。
- 产品信息变化后上传新资料；生成内容仍会保留本次引用的知识块 ID，便于追溯。

## 3. 创建和维护营销活动

进入“营销活动”，选择“新建活动”，填写：

- 活动名称和产品名称
- 活动目标、目标人群与主要城市
- 需要覆盖的小红书、抖音、公众号平台
- 内容语气、已确认的产品事实、必含信息、禁用表达和行动引导

保存后可随时“编辑 Brief”。选择“生成内容”会创建后台工作流；同一活动可以多次生成，保留独立运行批次。活动结束后可归档，归档状态不会再接受新生成任务；需要继续时可以恢复。

## 4. 模型生成与任务状态

生成工作流依次执行知识检索、内容策划、平台差异化生成、规则校验和一次自动修复。长任务不会占用浏览器连接，可在“任务队列”和“总览”查看进度。

系统默认使用明确标注的 Mock Provider，方便离线验收。管理员配置 OpenAI-compatible 模型端点或中立 HTTP 媒体 Provider 后，流程会切换到真实服务；界面不会把 Mock 结果描述为外部模型产出。

在活动卡片中展开“生成记录”，可以查看最近运行的状态、Provider、模型、Prompt 来源与发布版本、调用次数、Token 记录来源和追踪摘要。系统只保存输入输出摘要与字节数，不在运行记录中复制原始 Prompt 或正文；Provider 未返回 Token 用量时会明确显示“未上报”，不会用估算值冒充真实账单。失败运行只显示脱敏错误类型和已经完成的调用证据。

## 5. 内容编辑与人工审核

进入“内容审核”，左侧是待处理内容，右侧显示当前平台内容、自动校验记录和版本历史。

内容编辑可以修改标题、正文、话题标签和行动引导。每次保存都会：

1. 增加内容版本号；
2. 记录一条不可覆盖的版本历史；
3. 清空原批准状态，要求重新审核；
4. 把旧内容对应素材标为 `stale`，避免错发旧版本。

审核人员核对知识引用、产品事实、语气、平台格式和风险后，选择“确认通过”或填写原因后“驳回”。只有人工通过的当前版本才能进入素材和发布流程。

## 6. 素材管理

审核通过后，系统会把图片或视频/分镜任务交给后台 Worker。素材状态包括待生成、排队、处理中、已就绪、失败和旧版本失效。

编辑人员可以上传外部 AIGC 或人工设计素材，也可以重试失败任务。所有文件存储在受控对象存储中；浏览器通过鉴权下载接口访问，不直接暴露存储凭据。

## 7. 平台连接

只有管理员可以添加和测试平台连接。凭据由后端加密保存，API 和浏览器不会返回原始密钥。

- 抖音：需要开放平台应用、用户 OAuth、Access Token、Open ID 及对应 scope。
- 公众号：需要具备草稿/发布接口权限的 App ID 和 App Secret。
- 小红书：不收集账号密码，使用“审核后导出”连接，生成 ZIP 投放包后由运营人员人工发布。

连接测试通过只表示当前凭据和基础接口可用；最终发布能力仍受账号权限、平台审核、限流和素材规范约束。

## 8. 安排发布

进入“发布管理”，选择已经人工审核通过的内容、同平台连接和发布时间。系统会校验：

- 内容仍是当前已批准版本；
- 平台与连接器一致；
- 所需素材已就绪且没有过期；
- 排期操作由审核人员或管理员执行。

尚未开始的发布任务可以由审核人员取消。取消状态会持久化，后台 Worker 即使随后领取到对应队列任务也不会再调用平台接口。

小红书任务完成后下载 ZIP 投放包；抖音和公众号会按连接器能力调用真实接口。失败任务保留外部响应摘要和重试次数，不会显示虚假成功。

公众号提交后会显示 submitted 并由后台按 `publish_id` 自动查询，只有得到最终 `article_id` 才显示 published。审核人员在平台后台取得确定证据后，也可在 submitted 或待人工对账状态选择“确认已发布/确认未发布”；人工决定会停止对应自动查询任务，迟到结果不会覆盖人工状态。抖音缺少可靠作品 ID 的不确定结果仍需人工核对。

## 9. 数据复盘

已发布内容可以通过平台连接器回收指标，也可以在“数据复盘”选择“录入人工指标”，填写从平台后台核对的曝光、点击、点赞、评论和分享数据。“数据复盘”统一展示曝光、点击、互动、点击率和互动率，并根据确定性规则给出保守建议。

样本不足时系统只提示继续积累，不输出“最佳内容”等过度结论。比较不同平台或选题时，应保证统计周期和指标口径一致。

## 10. 团队与审计

管理员在“团队与审计”中可以：

- 创建新的隔离工作区；
- 按邮箱加入已注册用户；
- 调整成员角色或移除成员；
- 查看关键业务操作的时间、操作者、对象和脱敏详情；
- 查看当前生效 Prompt 来源、版本和哈希，基于当前版本创建不可变草稿；
- 展开待审批版本核对 plan/generate/review 全文与 SHA-256，由另一名管理员审批或拒绝；
- 创建包含 plan/generate/review 固定输入和确定性断言的不可变 Eval 套件，由另一名管理员激活；
- 对候选 Prompt 运行当前目标模型评测，查看通过/失败状态、输出哈希、字节数和失败断言；
- 只有通过当前 Eval 套件与当前目标 Provider/模型的版本才能审批、激活或回滚；
- 激活已审批版本，或把已退役历史版本回滚为当前版本。

Prompt 创建者不能审批自己的版本；Eval 套件创建者不能激活自己的套件。审批不等于生效，必须先通过当前目标 Provider/模型的活动 Eval 套件，再执行激活。激活和工作流运行都会重新校验正文哈希，并核验该次运行实际 Provider/模型的当前 Eval 通过证据；校验失败时系统在首次模型调用前拒绝使用。Prompt 与 Eval 用例正文只向当前工作区管理员返回；审计和评测运行结果不复制 Prompt、用例输入或模型正文。

生产环境的 Prompt 标题旁会显示“active”或“blocked”。出现“生成已被治理策略阻断”时，按页面提示补齐第二名管理员、活动 Eval 套件、目标模型评测、审批和激活；未就绪的生成请求不会进入任务队列。内置安全基线只用于创建第一个受治理草稿，不是生产可长期绕过审批的版本。

系统禁止管理员移除自己，也禁止把最后一名管理员降级，避免工作区失去管理入口。

## 11. 常见问题

**生成任务长时间未完成**

查看“任务队列”的状态和最近错误。模型超时会按退避策略重试；达到最大次数后，编辑人员修复配置并手动重试。

**内容通过后没有可用素材**

确认素材任务是否仍在处理、是否失败，以及内容是否又被编辑。编辑内容会让旧素材失效并创建新计划。

**无法安排发布**

确认当前账号至少是审核人员，内容已通过人工审核，连接器平台一致，并且当前版本所需素材已就绪。

**平台连接测试成功但发布失败**

基础凭据可用不代表账号拥有全部发布 scope。根据任务错误检查平台审核状态、素材规范、授权过期和接口限流。

**切换工作区后看不到原来的内容**

这是正常的数据隔离行为。使用顶部工作区选择器切回原工作区，或联系管理员把账号加入目标工作区。
