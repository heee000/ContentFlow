# 渠道配置与错误安全契约

日期：2026-09-23。对应 A30/A31/A32。本契约描述工作树实现；不是实机部署、历史凭据检查或真实平台验收证明。

## 1. 配置边界

`ChannelCreate` 校验分平台的封闭配置；未知字段和异常类型返回 422。API 校验错误不再回显 Pydantic 的 input/ctx，防止整份包含凭据的请求体进入响应。历史配置不自动转换或覆盖；连接测试、发布输入加载及连接器运行时重新检查，不合格配置在网络调用前拒绝。

| 平台 | 可配置字段 | 约束 |
| --- | --- | --- |
| 微信 | `auto_publish`、`author`、兼容字段 `api_base` | `auto_publish` 缺省 false，只接受 JSON true/false；作者为最长 120 字符的字符串；地址只能是 `https://api.weixin.qq.com`，或仅多一个末尾斜杠 |
| 抖音 | `open_id`、兼容字段 `api_base` | open_id 为最长 255 字符的字符串；地址只能是 `https://open.douyin.com`，或仅多一个末尾斜杠 |
| 小红书 | `export_format` | 只能是 zip |

连接模式和脚本确认人数继续从顶层受支持字段传入；不能通过嵌套 config 覆写内部字段。运行时的持久配置允许这两个内部字段，但确认人数必须是整数 1 或 2。

正式请求始终使用代码中的官方 HTTPS Origin，不拼接租户提供的地址。注入测试 Client 也不例外，测试使用 MockTransport，不设置虚构地址绕过正式规则。每次请求明确 `follow_redirects=False`，防止调用者注入开启重定向的 Client 后发送到别处。

这是应用层固定目的地，不是 DNS 污染、部署管理员代理或网络出口隔离的完整防护；A21 仍独立待验收。确需自建社媒代理应另行设计部署级授权，不恢复任意渠道地址覆盖。

## 2. 发布语义

- 只有严格 `auto_publish=true` 才调用微信公开提交。false 或缺省只创建草稿。
- 字符串、数字、null、数组、对象一律拒绝，不做 bool() 或批量转换。
- 预览和执行读取同一个严格配置。页面遇到历史异常开关显示配置错误并阻止新建预览，不继续提示“安全模式”。
- 配置变化仍受发布清单保护；不会更新旧清单使旧任务自动恢复。异常旧渠道由管理员检查后，通过受支持入口重新配置/创建，并重新确认发布物。

## 3. 安全诊断

连接器错误仅包含受控阶段、错误类别、HTTP 状态码和有界整数平台错误码。平台 errmsg/description、响应正文、请求 URL 和原始异常不进入公开错误。微信 40164 保留检查出口白名单的操作提示，不回显供应商原文。

HTTP/网络/JSON/平台错误转换成受控异常，阻断原异常链；敏感请求期间抑制 httpx 自带的包含完整 token URL 的请求日志。Worker 对连接测试、分发、对账、指标任务还有第二层兜底：未知异常只保留安全摘要，不记录 traceback。即使任务行已在异常前消失，也不会退回原始异常日志。

新发布错误保存安全诊断；API 返回固定状态说明和经过字段白名单校验的诊断。旧 PublishJob.error、Job.last_error 不在数据库中覆盖/删除，但平台任务响应不再原样暴露这些历史字符串。原记录及历史日志是否曾包含真实凭据，需在受控授权下另行核查；这次没有读取历史实机日志或轮换密钥。

## 4. 重试边界不放宽

- 鉴权失败、必需素材缺失、平台写入前读取失败：显式标记可安全重试；必要时渠道标记 invalid。
- 上传、建草稿、公开提交之后的失败或结果未知：仍进入 reconciliation_required，禁止自动重发。
- 连接器新安全异常不能绕过原来的未知结果分支。保留数据库故障分类和既有恢复机制，不因脱敏把不确定结果改成安全重试。
- 历史错误隐藏不意味着对应任务已处理，也不会删除人工核对记录。

## 5. 验证与升级

专项覆盖非法配置矩阵、官方目标/重定向、微信及抖音 HTTP/网络/JSON/平台错误、准确的外部调用次数、严格真假与预览一致、历史配置拒绝、API→Worker→viewer、数据库/日志不含秘密哨兵、历史证据保留、任务删除竞态。

所有测试只使用合成数据及 MockTransport；没有真实平台写入。完整测试数字和提交/CI/部署状态以 [实施进度](IMPLEMENTATION_PROGRESS.md) 为准。

当前工作树还包含 A25/A26 未收尾的预览/签名/幂等实现，新增请求契约要求 Web/API/Worker 协同升级。本轮可作为依赖完整、标注在制的功能分支快照普通同步；不得把本地安全测试或提交当作整棵工作树已经具备发布资格。合并/部署前仍须完成预览专项、真实 PostgreSQL 并发及浏览器验收，并协调版本。
